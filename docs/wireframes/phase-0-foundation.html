Ariadne wireframes · phase 0 of 4

Foundation

Nothing moves. One colour system replaces three, urgency stops being carried by colour alone, and every measurement in the interface lands on a 4px grid. This is the phase whose screenshot looks almost identical and whose diff touches every component.

Task P0 · Effort S · Depends on nothing · Layout unchanged

01/the problem stated precisely

Three colour systems, one channel

Indigo currently means "you can click this" and "this is the status" at the same time. Gold means brand. And urgency — the product's whole claim — is a 7px dot with four unlabelled states. Meanwhile adoStatusVariant() has no branch for Blocked, so the most urgent state on screen falls through to outline: the calmest treatment available.

One job per channel

ChannelOwnsNever
Indigo Interactive only — primary buttons, links, focus rings, selected state Status · urgency
Urgency The numeral and the sort position. Colour reinforces the top two bands only Decoration
Status Neutral outline by default; semantic fill reserved for states that demand action Brand expression
Gold The logotype, and the Today thread marker. Brand and meaning coincide in exactly one place General accents
Decision · score bands The proposal's 80/60/30 were placeholders. They don't need deriving — they're already in the repo. lib/scoring.ts tops out at 105 and getPriorityTier() already cuts at 60 / 40 / 25, aligned to NEEDS_ATTENTION_THRESHOLD. The chip inherits the tier that already sorts the list, so the colour a user sees and the order they see it in cannot disagree.

Urgency bands — derived, not chosen

TokenRangeChipReachable by
--urgency-critical≥ 60 92 Ready to merge, or any reason stacked with a deadline
--urgency-high40 – 59 45 Review requested · mentioned · ready to merge alone
--urgency-medium25 – 39 30 Stale own PR · assigned with a deadline
--urgency-low< 25 10 Assigned · authored · ad-hoc. Below the attention threshold

Only the top two bands are filled. Medium is an outline, low has no border at all — so the visual weight of the list falls off in the same direction the numbers do.

02/badge pass, previewed

Blocked stops whispering

P4 finishes the badge system in Phase 1, but the tokens land here, so the difference is worth seeing at token level first. Same six states, same labels, one legible hierarchy.

Guardrail check One inline badge per row survives. Nothing here adds a chip; the six variants are recoloured, not multiplied. adoStatusVariant() gains one branch — a /block/ test returning warning — which is also the bug fix hiding inside this task.

03/the a11y claim, proven

The greyscale proof

WCAG 1.4.1 says colour can't be the only carrier of information. The cheapest way to check that is to remove the colour. Here is the same row list twice — the right-hand copy has filter: grayscale(1) and nothing else changed.

Ranking survives, because it was never the colour doing the work — it was the numeral, the fill weight, and the order. Run the same test on the current dot column and the right-hand copy carries no urgency information at all.

04/density and the data face

Two row heights, one grid

All spacing becomes a multiple of 4px, and row height is fixed per mode so content can never reflow it. Everything measured — scores, IDs, durations, ages, counts — moves to a mono face, because it reads as a measurement rather than a word.

Decision · density default Comfortable. Compact wins on a screenshot and loses on a Tuesday afternoon. A tool opened dozens of times a day shouldn't ship at its tightest setting; the toggle lives in Settings and persists in the settings table.

05/delta

What changed

  • P0+Four urgency band tokens, derived from the existing getPriorityTier() cuts at 60 / 40 / 25
  • P0+Status tokens: --status-blocked, --status-neutral. Blocked gains a branch in adoStatusVariant()
  • P0+Mono data face on scores, IDs, durations, ages, counts
  • P0+Density toggle — 44px comfortable / 36px compact, persisted in settings
  • P0~Indigo restricted to interactive elements. Badges lose it entirely
  • P0~Gold restricted to the logotype and the Today marker
  • P0~All spacing on a 4px grid; row height fixed per mode
  • P0−Hard-coded hex in components — everything reads a token

Layout, counts, sections, and row grammar are untouched. The dashboard is byte-for-byte the same shape as the baseline; only the palette underneath it has a spine.
